# Issue tracker: GitHub

Issues, specifications, and tickets for this repository live in GitHub Issues at `caesar631/ai-career-ip-content-os`. Use the `gh` CLI for issue operations.

## Conventions

- Create an issue with `gh issue create`; apply `ready-for-agent` to an approved spec or ticket.
- Read an issue with `gh issue view <number> --comments`, including its labels.
- List issues with `gh issue list`, filtering by state or label when needed.
- Add comments with `gh issue comment` and change labels with `gh issue edit`.
- Close an issue only after its acceptance criteria are met.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## When a skill says "publish to the issue tracker"

Create a GitHub Issue in `caesar631/ai-career-ip-content-os`.

## When a skill says "fetch the relevant ticket"

Run `gh issue view <number> --comments`.
